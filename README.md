# 모노폴리 능력치 전환 룰렛

세 명 이상의 대상을 서로 다른 대상의 위치로 바꿉니다. 

## 링크

[바로가기](https://gaseu-rangers.github.io/stat_shift_roulette/)

## 사용 방법
1. 강점, 보통, 약점 항목에 각각 맞는 능력치를 적습니다.
2. 각 능력치는 ',(쉼표)'로 구분합니다.
3. 룰렛 돌리기 버튼을 누릅니다.

- 강점과 약점의 항목이 하나씩 선택되어 서로 바뀌게 됩니다
- 강점 및 약점 항목에 값이 존재하지 않다면, 값이 없는 채로 룰렛이 작동합니다.
- 이 경우 강점이 약점이 되기만 하거나, 약점이 강점이 되기만 합니다.
